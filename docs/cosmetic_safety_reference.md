# Cosmetic Ingredient Safety & Regulatory Reference

## 1. FDA Cosmetics Regulations (USA)

### Labeling Requirements
*   **Manufacturer/Distributor:** Name and place of business must be listed.
*   **Net Quantity:** Content weight/volume.
*   **Ingredient Declaration:** Listed in descending order of predominance using INCI names.
*   **Traceability:** Lot/batch number (MoCRA requirement).
*   **Warnings:** Specific warnings for certain products (e.g., aerosols, tanning).

### Banned & Restricted Ingredients
The FDA prohibits or restricts a specific set of ingredients.

| Ingredient / Category | Status | Details |
| :--- | :--- | :--- |
| **Bithionol** | Banned | Causes photocontact sensitization. |
| **Chloroform** | Banned | Banned as an ingredient; residuals from manufacturing may be acceptable. |
| **Chlorofluorocarbon (CFCs)** | Banned | Environmental protection; aerosol propellants prohibited. |
| **Halogenated salicylanilides** | Banned | Causes photocontact sensitization. |
| **Hexachlorophene** | Banned | Toxic; allowed only by prescription. |
| **Mercury compounds** | Banned | Exception: preservative in eye-area products at trace levels. |
| **Methylene chloride** | Banned | Probable carcinogen. |
| **Vinyl chloride** | Banned | Carcinogen; banned in aerosols. |
| **Zirconium complexes** | Banned | Toxic to lungs; banned in aerosols. |
| **Sunscreen actives** | Restricted | Regulated as OTC drugs; must meet monographs. |
| **Color additives** | Restricted | Must be specifically FDA-approved. |

## 2. EU Cosmetics Regulations (Europe)

### Selected Banned & Restricted Ingredients (Annex II & III)
The EU maintains extensive lists of prohibited (Annex II) and restricted (Annex III) substances.

| Ingredient | Status | Details |
| :--- | :--- | :--- |
| **Mercury & compounds** | Banned | Toxic (Annex II); trace exception for eye preservatives. |
| **Lead & compounds** | Banned | Neurotoxin (Annex II); no safe level. |
| **Arsenic & compounds** | Banned | Carcinogen (Annex II). |
| **Cadmium & compounds** | Banned | Carcinogen & Endocrine disruptor. |
| **Lilial** (Butylphenyl methylpropional) | Banned | Reproductive toxicant (Banned Mar 2022). |
| **Formaldehyde** | Restricted | Max 0.2% (0.1% oral); warn if >0.05%. |
| **Parabens (Long-chain)** | Banned | Isopropyl, Isobutyl, Phenyl, Benzyl, Pentylparaben. |
| **Parabens (Short-chain)** | Restricted | Methyl, Ethyl, Propyl, Butylparaben (strict limits). |
| **Triclosan** | Restricted | Allowed only in specific products/limits. |
| **Hydroquinone** | Restricted | Banned in skin; Nail products only (0.02%). |
| **Resorcinol** | Restricted | Hair dyes only. |
| **Oxybenzone** (Benzophenone-3) | Restricted | Max 6% (face/body), 0.5% (lips). Endocrine concerns. |
| **Homosalate** | Restricted | Max 7.34% (Endocrine concerns). |
| **Octocrylene** | Restricted | Max 9% (Benzophenone formation concerns). |
| **Nitrosamines** | Restricted | Max 50 µg/kg (impurity limit). |
| **PFAS compounds** | Under Review | ECHA restriction proposal; some banned. |

## 3. Toxic Ingredient Classifications
*Sources: IARC Monographs, EU SCCS Opinions, EWG, Safe Cosmetics Campaign.*

### Carcinogens (IARC Group 1, 2A, 2B)
Ingredients linked to cancer or tumor promotion.

| Ingredient | Found In | Classification & Risk |
| :--- | :--- | :--- |
| **Formaldehyde** | Nail polish, hair straightener | IARC 1; Leukemia/Nasal cancer. |
| **Coal Tar Dyes** | Hair dye, lipstick | IARC 1; Bladder/Skin cancer. |
| **Benzene** | Fragrance, solvents | IARC 1; Leukemia. |
| **Ethylene Oxide** | PEGs, emulsifiers | IARC 1; Breast/Peritoneal cancer. |
| **Mineral Oil** (untreated) | Lip balms, creams | IARC 1; Skin cancer. |
| **Cadmium/Chromium/Arsenic** | Pigments, talc | IARC 1; Lung/Skin/Kidney cancer. |
| **Acrylamide** | Thickeners | IARC 2A; Mammary tumors. |
| **Methylene Chloride** | Solvents | IARC 2A; Liver cancer. |
| **BHT** | Antioxidants | IARC 2B; Tumor promoter. |
| **Asbestos** | Talc (contaminant) | IARC 1; Mesothelioma. |
| **DEA / Nitrosamines** | Foaming agents | IARC 2B/1; Stomach/Esophageal cancer. |
| **PAHs** | Petrolatum, fragrance | IARC 1; Lung/Skin cancer. |

### Allergens (High Incidence)
Ingredients known to cause contact dermatitis or sensitization (EU SCCS / Annex III).

| Ingredient Category | Specific Ingredients | Risk |
| :--- | :--- | :--- |
| **Fragrance Allergens** | Linalool, Limonene, Geraniol, Citral, Coumarin, Citronellol, Eugenol, Alpha-Isomethyl Ionone | EU 26+ list; 10-20% dermatitis rate. |
| **Preservatives** | Phenoxyethanol, DMDM Hydantoin, Imidazolidinyl Urea, Bronopol, Quaternium-15 | Dermatitis, Formaldehyde releasers. |
| **Isothiazolinones** | Methylisothiazolinone (MIT), Methylchloroisothiazolinone (MCI) | Airborne allergy; restricted <0.0015%. |
| **Banned Fragrances** | Lyral (Hydroxyisohexyl 3-Cyclohexene Carboxaldehyde), Oakmoss, Tree Moss | Extreme sensitizers; banned or restricted. |
| **Metals** | Nickel Sulfate, Cobalt Chloride | Contact dermatitis leaders. |
| **Synthetic Dyes** | Red 7 (CI 15850), Yellow 5 (CI 19140), Red 33 (CI 17200), Blue 1 (CI 42090) | Coal tar derivatives; 5-15% allergy rate. |
| **Resins** | PTBP Formaldehyde Resin | Nail polish sensitizer. |

### Hormone / Endocrine Disruptors (EDCs)
Ingredients that may mimic hormones or interfere with the endocrine system (EU Cat 1/2A, SCCS Suspects).

| Ingredient | Found In | Classification & Risk |
| :--- | :--- | :--- |
| **Parabens** | Preservatives | EU ED Cat. 1; Estrogenic, breast cancer link. |
| **Phthalates** (DBP, DEHP) | Nail polish, fragrance | EU Banned CMR; Reproductive toxicity. |
| **Oxybenzone** (Benzophenone-3) | Sunscreen | EU ED suspect; Thyroid/Estrogen mimic. |
| **Homosalate** | Sunscreen | Androgenic/Estrogenic. |
| **Octinoxate** | Sunscreen | Pesticide amplifier; Estrogenic. |
| **Octocrylene** | Sunscreen | Scrutiny over benzophenone formation. |
| **Triclosan / Triclocarban** | Antibacterial | Thyroid disruptor; antibiotic resistance. |
| **BHA** | Antioxidants | EU ED Cat. 1; Thyroid tumors. |
| **Resorcinol** | Hair dye | Thyroid inhibitor. |
| **TPHP** (Triphenyl Phosphate) | Nail polish | Persistent ED; Benzophenone precursor. |
| **Nonylphenol Ethoxylates** | Surfactants | Estrogenic; aquatic toxin. |
| **Hydroquinone** | Skin lighteners | Thyroid/Estrogen disruptor. |

**Analyzer Note:**
When classifying ingredients:
*   **High Hazard:** Banned ingredients, IARC Group 1 Carcinogens, EU ED Cat 1.
*   **Medium Hazard:** Restricted ingredients (if over limit), Allergens, Suspected EDs.
*   **Low Hazard:** Approved ingredients within limits.
